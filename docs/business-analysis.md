# 競合調査：MyChara / nyaan

調査日：2026-10-29。対象は https://mychara.ai と https://nyaan.co の公開ページ、および公開されているフロントエンドのコード（法務文書・料金設定が埋め込まれている）。

## 1. そもそも何のサービスか

**動画生成ではなく「AIキャラクター会話（ロールプレイチャット）」のプラットフォーム**です。

- ユーザ（クリエイター）がキャラの設定（名前・紹介文・基本設定・プロフィール・導入文・タグ）を作って公開する
- 他のユーザがそれを読んで選び、AI と会話する（返答は LLM が設定をもとに生成）
- 付加機能：ボイス（キャラが台詞を読み上げる TTS）、キャラ画像生成、会話シーンを読み物として公開する「リプレイ」、複数キャラで共有する「世界観設定」、投稿イベント
- 公開範囲：公開／限定公開／招待制／非公開

nyaan.co はタグライン・ページ構成・お知らせ（`2026-07-summer-contest`）が MyChara と同じで、**同じ運営による別ブランド（または同一コードベース）と見られます**（推測。運営会社の表記は確認できず）。

運営：MyChara株式会社（2026年5月設立、東京都中央区銀座）。

## 2. ビジネスモデル

収益は **サブスク＋ポイント（従量課金）のハイブリッド**です。

| プラン | 月額 | 年額 | 会話回数 | ボイス | 特典ポイント |
|---|---|---|---|---|---|
| Free | 0円 | — | 10回/日 | 5回/日 | — |
| Plus | 980円 | 10,000円 | 3,000回/月 | 1,500回/月 | 300pt/月 |
| Premium | 1,500円 | 15,000円 | 6,000回/月 | 3,000回/月 | 600pt/月 |
| Pro | 3,000円 | 30,000円 | 30,000回/月 | 7,500回/月 | 1,500pt/月 |
| Ultimate | 30,000円 | — | 無制限 | 無制限 | ポイント消費なし |

（米ドル建ても併設：Plus $5.99、Premium $11.99、Pro $17.99、Ultimate $200）

ポイント（1pt≒1円、高額ほどボーナス）：300pt/300円、510pt/500円、1,030pt/1,000円、3,150pt/3,000円、5,300pt/5,000円、11,000pt/10,000円、22,400pt/20,000円、34,500pt/30,000円。

- **プラン枠を超えた会話や画像生成はポイントで払う**。画像生成は「quick / arrange」などの種類と画質（standard / high / stable）ごとに消費ポイントが設定されている
- 登録ボーナスとして無償ポイントを付与
- **有償ポイントと無償ポイントを分けて管理**している（資金決済法の前払式支払手段への対応）
- 招待・ギフトの仕組みあり（招待で特典ポイント）

### クリエイター還元

- 自分の公開キャラから生じた売上の一部を「R」という単位で報酬として積み、日本国内の銀行口座に円で支払う
- 本人確認・口座登録が必須、保留期間と最低出金額がある
- 外部での実況・動画投稿・配信の収益化は許可制なしで OK（集客のため）

つまり **「クリエイターがキャラ（＝コンテンツ）を供給し、運営は LLM 原価に上乗せした会話課金で稼ぎ、一部をクリエイターに戻す」** という、UGC プラットフォーム型のモデルです。

## 3. 決済

- **Stripe**（クレジット・デビット、Apple Pay、Google Pay、Link、コンビニ決済、銀行振込）
- コンビニ・銀行振込はサブスクと1,000円以上のポイント購入のみ
- 利用規約で「Stripe 等の決済事業者が禁止・制限する内容」を禁止しており、性的コンテンツは決済リスクの観点から厳しく制限している

## 4. モデルの仕入れ（推定を含む）

公開コードから LLM の名前は確認できませんでした（サーバ側で隠している）。判明・推測できたこと：

- **会話（LLM）**：API 経由の外部モデル。名前は非公開
- **ボイス（TTS）**：`speaker_ref_id` / `ref_latent` / `model_kind: base | voice_design` という形の、自社で用意したエンドポイントに署名付きで送る構成。**オープンソースの音声合成モデルを自前 GPU でホストしている**と見られる
- **画像生成**：画質ごとに standard / high / stable の段階がある。外部 API かセルフホストかは不明

### 仕入れ先の選択肢

| 用途 | 選択肢 | 特徴 |
|---|---|---|
| 会話 LLM | **OpenRouter** | 1つの API キーで多数のモデルを切り替えられる。手数料が上乗せされる |
| 会話 LLM | **BytePlus ModelArk**（Seed 系） | OpenAI 互換 API。Waffo は BytePlus のパートナー契約があるため、仕入れ条件で有利な可能性 |
| 会話 LLM | DeepSeek・Qwen などの直接 API | 原価が最も安い部類 |
| 会話 LLM | 自前 GPU で vLLM | 量が増えたら最安。初期は割高で運用負荷も大きい |
| 画像 | fal.ai / Replicate / BytePlus Seedream | 1枚あたりの従量課金 |
| 動画 | BytePlus Seedance、Kling など | 1本あたりの単価が高い → ポイント消費を大きく設定する |
| TTS | 自前ホスト（オープンモデル）／ ElevenLabs など | 自前なら単価は安いが GPU の固定費がかかる |

本実装の LLM 接続は **OpenAI 互換 API** なので、`LLM_BASE_URL` を変えるだけで上記のどれにも切り替えられます。

## 5. 採算の目安（概算・要検証）

1回の会話で入力 約3,000トークン（設定＋履歴）、出力 約250トークンと仮定。1ドル=150円で計算。

| モデル単価の想定 | 1回あたり原価 |
|---|---|
| 安価モデル（入力 $0.3/M・出力 $1/M 程度） | 約0.17円 |
| 中位モデル（入力 $3/M・出力 $15/M 程度） | 約1.9円 |

- Plus（980円で3,000回）の売上は1回あたり約0.33円。**枠を使い切るユーザが多いと、中位モデルでは大赤字**になる。安価モデル＋プロンプトキャッシュ＋履歴の上限が前提
- ポイント課金（1回1pt＝約1円）は安価モデルなら粗利率80%以上
- 実際の単価は各社の料金表で必ず確認すること（上の数字は概算です）

## 6. 法務の要点（専門家への確認を推奨）

- **特定商取引法に基づく表記**：必須（`public/legal.html` にひな形あり）
- **資金決済法（前払式支払手段）**：有償ポイントの未使用残高が基準日（3/31・9/30）に1,000万円を超えると届出と供託が必要。有償と無償を分けて管理し、残高を集計できるようにしている（`/api/admin/funds-report`）
- **決済事業者の規約**：Stripe は性的コンテンツの扱いが厳しい。違反すると決済停止のリスク
- **クリエイターへの支払い**：本人確認、源泉徴収やインボイスの扱いは税理士に確認
- **未成年の利用**、生成 AI コンテンツの表示、著作権・肖像権（実在人物・既存作品のキャラ）の扱い
